# Videoader v26.9.21+4 — 更新检查修复

- 统一应用与 GitHub Release 的日期版本编号，修复旧发布被反复提示为新版本的问题。
- 支持数字版本排序及同日构建号比较，明确显示“已是最新版”或“本地版本更高”。
- 版本标签无法识别时显示具体原因，不再笼统提示网络错误。
- 下载按钮打开检查到的具体 Release，避免跳转到其他发布。
- 包含此前的独立下载进度、ETA、日志折叠、音视频合并校验及桌面界面改进。

Windows x64 便携包请完整解压运行，外部工具仍需单独配置。

发布此包请创建标签 **`v26.9.21+4`**，与应用内版本保持一致。以后同日更新递增构建号，避免混用 `1.x.x` 与日期版本。旧版本已经存在的错误编号无法通过远端标签自动修复，需要安装此版一次。
