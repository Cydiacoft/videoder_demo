# Videoader v1.1.1 — 独立任务状态与 ETA 修复

- 修复视频下载进度和 ETA 消失的问题。
- 下载页新增固定状态栏，日志收起时仍能查看当前流百分比、速度、ETA、音视频合并、后处理、成品校验以及完成或失败结果。
- 支持 yt-dlp 和 Aria2 进度；没有可靠 ETA 的阶段显示“暂不可用”，下载到 100% 不代表后处理已完成。
- 本地 FFmpeg 工具和专业工作台新增独立任务状态栏。
- 日志保留详细诊断信息和阶段变化，支持复制，不再自动展开或被连续进度刷屏。

下载 Windows x64 便携包后完整解压运行 `videoder_demo.exe`，不要单独移动 exe。本包不含 FFmpeg、yt-dlp 或 Aria2，需要在设置中配置。
