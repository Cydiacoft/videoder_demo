# Videoader v1.1.0 — 更紧凑的桌面体验与音视频下载校验

本版继续完善 FFmpeg Studio 桌面工具箱，重点改进下载成品检查、界面布局与应用标识。

## 本次更新

- 网络视频明确请求视频与音频，默认合并成 MKV；下载完成后通过 ffprobe 校验视频流和音轨，缺轨文件不再仅凭退出码显示“完成”。
- 被下载记录或自定义参数跳过的任务显示为“跳过”，与真正完成区分。
- 缩小导航与控件间距，侧栏底部增加分隔线和更清晰的引擎状态区域，“就绪”状态点改为绿色。
- 下载日志支持展开和收起，开始任务时自动展开。
- 全新紫色波形与播放图标，替换默认 Flutter 应用图标。
- Cookie 读取失败提供中文处理指引，区分浏览器数据库占用与解密失败。

## 安装与使用

下载 Windows x64 便携包并完整解压，运行 `videoder_demo.exe`。请保留同目录的 DLL 与 data 文件夹，不要只复制 exe。

本包不包含 FFmpeg、yt-dlp 或 Aria2。请在设置中配置本地工具；视频成品检查需要 ffmpeg 同目录中的 ffprobe。

## 注意事项

- 以前下载的无声文件不会自动修复，请用新版重新下载；如果同名旧文件被跳过，请更换输出文件名。
- MKV 不会重新编码，保留所选视频和音频的原始编码；播放 HDR/HEVC 等内容仍需要播放器支持。合并容器可在下载参数中修改。
- 浏览器 Cookie 读取仍可能受浏览器后台占用或系统加密限制；网站风控和账号权限也可能影响下载。
- 本版支持 Windows x64；其他平台的图标资源已更新，但未完成发行验证。
